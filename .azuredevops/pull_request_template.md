## Descrição da Pull Request

**Título:** [Breve descrição da alteração]

### Resumo

Uma breve descrição do que a PR faz e por que é necessária.

### Mudanças Realizadas

- [ ] Adicionado nova funcionalidade X
- [ ] Corrigido bug Y
- [ ] Atualizada a documentação
- [ ] Refatorado o código Z

### Motivação

Explique por que essas mudanças são necessárias. Quais problemas elas resolvem? Como melhoram o projeto?

### Como Testar

Instruções para testar as mudanças. Inclua informações sobre o ambiente de teste, passos a seguir e possíveis resultados.

### Checklist

- [ ] O código está testado?
- [ ] A documentação foi atualizada?
- [ ] O estilo do código segue as diretrizes do projeto?
- [ ] Revisores foram atribuídos?

### Informações Adicionais

Qualquer outra informação relevante, como links para issues relacionadas, comentários sobre a implementação, etc.
